# TEST17.1
1. Remove old LSoundFont VST3 from scan paths (same plugin ID); install LSFX. Scan REAPER.
2. Open FluidR3 GM.sf2. Play same MIDI, host sample rate and block size as TEST1. Compare REAPER Performance Meter at rest, 1 note, 4 notes, and full MIDI arrangement. Use generic UI to compare Fourth order / Seventh order and effects Off / Both. Compare dry sound separately from effects; no claim of equal wet sound.
3. Check sustain, note-off, program changes, channel 10 drums, panic and release. Verify silence after release with effects off; verify effects tails with effects on.
4. Open an SFZ with samples in its original relative directory. Play MIDI channel 1; test velocity layers, sustain, release, pitch wheel, CC, and sample offsets. Test switching from SF2 to SFZ and back, missing samples, save/reopen project. SFZ is single instrument, not 16 independent channels yet; aftertouch and complete SFZ opcode coverage not validated.
5. Test realtime and offline render, sample rate changes, host blocks larger than 1024. Confirm TEST1 state restoration and keyboard accessibility. No Windows compile or REAPER runtime tests performed here.

6. On editor entry NVDA should focus Open SF2 or SFZ (button). Alt+L opens Parameters; Esc returns to the Parameters button. Verify each accelerator focuses rather than invokes.
7. Grid navigation: Home/End first/last, Up/Down adjacent, Page Up/Down five rows, Enter to value. Left/Right changes step (1/5/10/15/20); Up/Down and Page Up/Down change value, Enter goes back. Verify value and step announcements and that REAPER does not steal the arrows.
8. SF2: test filter cutoff, resonance, attack/release, tuning on a single channel; compare other channels and reset with Backspace. Confirm bank/program and effects still work. Save/reopen and check explicit edits.
9. SFZ: use an instrument containing label_ccN and set_ccN opcodes; check names, current values and MIDI response, including saving and restoring changes. Test an SFZ without CC labels. Check no effect on unedited sound and CPU at rest/playing.

10. TEST8 CPU: with Effects Both, play notes, release sustain, wait for tails then at least two seconds of silence. Alt+S to hear status: Active voices should be 0, SF2 idle sleep yes. If the persistent spike returns, record the numbers BEFORE pressing Panic, then compare after Panic; note whether SF2 or SFZ was active and the effect type.
11. Test all 8 reverb and chorus types, independent stereo/ping-pong delay, parameter reset and state restore. Verify SF2 native CC91/93 sends on Room/Hall/Plate and Chorus 1-4; master variants are not channel sends. Compare SFZ without FX and with FX. Check for stale echoes after mode changes; test 1-second delay and feedback.
12. Compare output level against TEST6 at same preset/gain, try trim 0/12/24 dB and ensure loud chords do not overload downstream FX. Run standalone DSP test: g++ -std=c++17 -O2 Tests/OutputStageTest.cpp -o test_output && ./test_output. This does not compile the VST3.

13. TEST9 focus: open FX chain, switch to another FX and return; verify the host list is never robbed of focus and the first tab stop is Open SF2 or SFZ. Leave with native Escape, enter again, test Tab/Shift+Tab and file chooser cancel. Alt+L then Alt+G/Alt+O: verify there is no intermediate focus announcement.
14. Grid: from first cell try Up/Left, at last row try Down, at last column try Right. Home/End reach first/last globally. Page moves five within a column. Type `fil`, `rever`, `chor`, and repeat `r`; use Shift for reverse. Wait one second then type another prefix. Alt+Up/Down and Alt+Left/Right repeatedly; release Alt and immediately navigate plain arrows. Verify focus stays on Grid and value changes are spoken by the focused control. Repeat from Value and main Output gain. Home=minimum and End=maximum in either slider.
15. Compare TEST8 and TEST9 with identical settings and same MIDI. Below the final soft ceiling TEST9 is 6.02 dB louder; verify both engines and test high gain/trim. The sample ceiling is not true-peak protection. Existing projects sound louder too.
16. Standalone incremental search test: g++ -std=c++17 -O2 Tests/IncrementalParameterSearchTests.cpp -o test_search && LC_ALL=C.UTF-8 ./test_search. Windows compilation and REAPER/NVDA behavior are not verified locally.

17. TEST10: load FluidR3, wait for Loaded, then play from the beginning of a multichannel GM MIDI item with different Program Changes (including channel 10). Inspect Bank/Program for each channel and use Alt+S to verify received count and last program. Test programs 0, 1, 63, 64, 65, 127, repeated program changes, CC0/32 immediately preceding Program Change, and channels 1 and 16. Test a mid-song program change, restart and project save/reopen. Verify no CC0 misrouting to the next channel and check that existing CC automation still works. The bundled MIDI regression file uses all 16 channels with distinct programs; channel 10 is percussion. The host may cache VST3 mapping: restart REAPER and clear/re-scan if necessary.

18. TEST11: open Parameters, select Reverb level, hold Alt+Up repeatedly, then release Alt and navigate using plain arrows. Verify the selection remains valid and the displayed value follows every edit. Repeat on CC91, a generator, an FX choice, and Value mode. Alt+Home=maximum, Alt+End=minimum. Plain Home/End on Grid=first/last.
19. Load FluidR3 and play Tests/GM-FX-reception.mid from the start. Confirm Program, CC91 and CC93 counts; GS reset and effect macro changes should appear in the grid. Test Follow MIDI vs Manual: Manual must leave global FX settings unchanged by MIDI macro messages, but receive per-channel CC sends. Test the original MIDI file and check status with Alt+S if results differ. Test both engines, idle CPU and panic. A full MIDI device emulation is not implied.

20. TEST12: load the same SF2 and MIDI in LSFX and the reference player, matching overall gain, effects, start position, and CC7/CC11. Try SF2 channel 10 trim at 0 and +3 dB; the latter affects only channel 10 dry audio before the master. Compare LJuno Glue and Linear (soft ceiling). Alt+S reports channel 10 CC7/CC11 and bank/program without moving focus. GS/XG part-volume reception is covered by the parser tests; arbitrary GS/XG part mapping and per-drum proprietary messages are not covered. Verify saved state, MIDI resets, and that SFZ remains unchanged. Compare active and idle CPU with TEST11. Optional Linux-only `python Tests/FluidRoutingTest.py /path/to/FluidR3.sf2` checks FluidSynth dry routing and gain using the installed library; does not build the VST3.
21. Press Enter on Open SF2 or SFZ, choose a file, and listen for the returned button and loading/completion status. Repeat for SFZ, cancellation, a failed load and a large bank. Verify Tab moves normally and focus is not stolen from REAPER after moving away. Alt+A performs Panic directly; Alt+S speaks diagnostics directly; neither appears in Tab order. Verify both shortcuts in Parameters as well as on the main panel.

21. TEST13: start with a fresh instance, load the same SF2 in LSFX and the reference player. Set Effects Off and match output gain; compare channel 10 and melodic channels without trim or Glue. Inspect peak levels and reduce master gain if reference mode clips. Toggle SF2 master dynamics between Reference, Linear and LJuno Glue; no constant boost should appear below the dynamics threshold. Compare with the effects enabled at matched CC91/93. Try Scoring ambience, verify default CC91=40 then send CC91=0 explicitly (must stay 0 across profile changes); try CC91=90, edit the send, issue GM reset and check default return. Verify MIDI program changes, focus, reload, state persistence and idle CPU. Existing saved projects can retain older settings; use a new instance for the clean default comparison. SFZ has unchanged processing code but new shared defaults.
