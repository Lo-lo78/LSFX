Overview

LSFX is an accessible, multitimbral VST3 instrument for Windows x64, designed for keyboard and screen-reader operation in REAPER. It uses FluidSynth for SF2 and sfizz for SFZ. Its defining feature is a single, editable MIDI program map assembled from many libraries: combine complete SF2 banks, individual SF2 presets and SFZ instruments, then save the entire configuration as a reusable LSFX preset. Sixteen MIDI channels can play different instruments concurrently.

Installation and first sound

Extract LSFX.vst3 (the entire bundle) from the Windows x64 package into your VST3 folder, typically C:\Program Files\Common Files\VST3. Rescan the plug-ins in REAPER, insert LSFX on a track and open its editor. Press Alt+O to open a SoundFont or SFZ. Wait until loading finishes. Send MIDI notes on the selected MIDI channel; channel 10 starts at bank 128, program 000 for percussion. A blank location is silent. LSFX includes no sample libraries. Keep the samples and relative paths of SFZ instruments intact.

Virtual MIDI map

The standard visible map contains melodic banks 000–127 and percussion bank 128, each with programs 000–127. Additional bank addresses found in imported sources or selected by MIDI can be represented up to 16383. Bank Select (CC0/CC32) and Program Change select virtual addresses, not the original source address. The bank announcement includes its source names; the program announcement includes its name and source. Alt+O replaces the map with the selected library. An SF2 uses its original bank/program addresses; an SFZ supplies an individual instrument. Alt+K and Alt+P remain available even when the map is empty.

Import an entire bank

Select the MIDI channel with Alt+M, then the destination bank with Alt+K and the arrows. Press Enter to open the Windows file browser, choose an SF2, then select its source bank and press Enter. Only the destination bank is replaced; program numbers within the imported bank are preserved. Other banks remain unchanged. Escape cancels.

Import a single program

Select the destination bank and program with Alt+K and Alt+P. Press Enter on Program and choose either an SF2 or an SFZ in the file browser. For SF2, select the source bank, press Enter, select its source program and press Enter again. For SFZ, the file is assigned directly. Only the selected virtual address is replaced. For example, bank 000 program 003 can contain an SFZ slap bass, program 004 an SF2 piano from another bank, and program 005 strings from a third library. The source files are never rewritten.

Stereo mixing and routing

The standard build exposes 64 stereo pairs: Main 1/2 plus 63 auxiliary outputs, 3/4 through 127/128 (128 mono pins total). Alt+U selects the channel gain strip and Alt+R the routing strip. Left/Right moves between the 16 MIDI channels; Up/Down changes the value. Each strip is one Tab stop. Many MIDI channels may share an audio destination. In REAPER, configure the instrument track with enough track channels and enable the desired plug-in output pins or use the FX chain command to build multichannel routing. Create receives from the desired stereo pairs. An auxiliary route removes that channel from the direct Main mix; it keeps stereo, synthesis parameters, gain and compression but bypasses shared LSFX effects and master processing. Previously generated effect tails may decay on Main. SFZ-internal effects remain part of the instrument. Alt+G controls Main only.

Channel compressors and instrument gain

Each MIDI channel has its own stereo-linked, 1176-inspired parallel compressor. Alt+L exposes Threshold (-60 to 0 dB), Ratio (4:1, 8:1, 12:1, 20:1), Attack (20–2000 microseconds), Release (20–2000 ms), Gain (-36 to +36 dB) and Mix (0–100%). Mix defaults to 0% (transparent bypass). Compression follows the channel when the program or output changes; channels sharing an output are compressed separately before summing. The SF2 native shared effects receive their sends before dry compression. SFZ instrument gain (-60 to +24 dB) additionally trims the specific virtual program, independently of MIDI channel gain. Two locations referencing the same SFZ can have different trims. This is particularly useful for balancing instruments from different libraries.

Parameter grid

Alt+L opens the grid for the current MIDI channel and instrument type. An empty or loading location shows only channel gain and routing; a loaded SF2 exposes MIDI CCs, native generator offsets (filter, envelope, tuning and modulation), interpolation, compressors and effects; a loaded SFZ exposes its instrument gain, sample quality, labeled CCs, compressor and shared effects. Up/Down navigate within a column, Left/Right between columns, Home/End reach column boundaries, Ctrl+Home/End the entire grid. Page Up/Down move by up to five rows within the column. Type the parameter name to search; Shift reverses the search direction. Enter or Tab enters the value control; Enter returns to the grid. Alt+V focuses the value. Alt+Up/Down adjusts the value directly; Alt+Left/Right changes the numerical step (1, 5, 10, 15, 20); Alt+Page Up/Down makes larger adjustments; Alt+Home sets maximum and Alt+End minimum. Backspace resets supported parameters. Esc or Alt+C returns to the originating control.

Save, recall and portability

Ctrl+S saves the current LSFX preset (or opens Save As if unnamed); Ctrl+Shift+S saves under a new name. The .lsfx file in Documents\LSFX contains the complete map, source paths, MIDI programs, parameters, gains, compressors, routing and effects. Alt+B opens the preset browser: use arrows, Home/End, Page Up/Down or the initial letter to navigate, Enter to open/load, Backspace to go up, F2 to rename, Ctrl+N to create a folder, Delete with confirmation, Shift+F10 for the context menu, Escape to close. REAPER also stores the plug-in state. The presets reference external sources by absolute path; they do not embed samples. Keep external disks mounted and SFZ sample trees intact. If a referenced source is missing, reconnect it and use Retry; Cancel or Escape dismisses the prompt. Browser preferences are kept in %APPDATA%\Lo-lo\LSFX.settings.

Panic, initialize and About

Ctrl+Enter performs MIDI Panic: stops notes and clears effect tails without deleting the map. Alt+I requests confirmation before unloading instruments and resetting the instance; saved files and personal settings remain intact. Alt+A opens About. Its read-only text supports normal caret navigation, selection and Ctrl+C. Tab/Shift+Tab cycles between text, Project, Contact and Close; Enter opens a link or closes About; Escape or Alt+C closes it and restores previous focus. Announcements are delegated to the active screen reader, without SAPI fallback. Alt+S reads status and diagnostic information.

Memory and troubleshooting

Multiple SF2 programs can share a loaded source. SFZ instances are managed per concurrently active channel; when an additional instance is not ready yet, its first notes may be silent during preparation. Large maps can require significant RAM. Check the selected MIDI channel, program, output pair, REAPER routing, and channel gain if no sound is heard. If a source file is missing, verify its absolute path and any dependent samples. The separately labeled SF2 stereo recovery build is for diagnostics only: it does not offer isolated SF2 outputs or per-channel SF2 compression. The normal 0.99.2 TEST31.1 build retains the validated TEST26.1 multigroup fix.

Export SoundFont (TEST28)

Alt+E opens the native Save dialog to export the hybrid SF2/SFZ map as a standalone PCM16 SF2. Selected SF2 presets and their required samples are retained; each SFZ is converted into one program at its mapped address. Conversion preserves sampled regions, mono/stereo audio, velocity layers, pitch, loops, source volume, pan, filters and envelopes where possible. Synthesis differences, unsupported opcodes and omitted regions are reported; round robin and random are reduced to a fixed choice and release triggers are omitted. Sampleless oscillators and missing samples stop export. LSFX-specific processing is excluded. Escape cancels; Space or Enter dismisses OK. Source files remain unchanged and their licenses still apply.

SF2 note mixer

Delete on Bank or Program clears the destination after confirmation. Alt+Enter opens the note grid with MIDI Learn off; Alt+M toggles it. Up/Down navigates notes and Left/Right navigates Output, Level, Pan and Pitch. Alt+Up/Down edits, Alt+Page Up/Down changes numeric values coarsely, Alt+Home/End sets maximum/minimum, Alt+Left/Right changes step. Home/End navigates the column; Ctrl+Home/End navigates the entire grid. Silent boundaries. Backspace resets, Delete removes, Esc closes. SF2 changes affect new notes and persist in LSFX presets. SFZ note DSP is not yet implemented. Windows validation is required.
