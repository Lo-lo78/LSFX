# LSFX 0.99.3 TEST39

28 November 2026 · Windows x64 VST3 · Lo-lo

LSFX is an accessible multitimbral SF2/SFZ instrument for REAPER. Its defining feature is a fully editable MIDI bank/program map combining complete SoundFont banks, individual SF2 presets and SFZ instruments from multiple sources. Save the entire hybrid map as an LSFX preset or export it as a standalone SoundFont. Sixteen independent MIDI channels, 64 stereo audio outputs (Main 1/2 and 63 auxiliary pairs 3/4–127/128), 16 stereo parallel compressors, channel gains, SFZ program-specific gain, shared Main effects and keyboard/screen-reader navigation make it a flexible mixing instrument.

## TEST39 — Multi-program instrument projects

F6 now contains Project bank (000–128) and Project program (000–127) combo boxes, followed by Save project, Save project as, and Export library. Bank/Program navigation follows the main map eight-row grid and silent boundaries. Bank selection never writes anything; Enter moves to Program. Enter on Program stores a snapshot of the current instrument in that slot (occupied slots require confirmation with Cancel initially focused). Space loads the stored instrument into F3; Delete removes a saved slot after confirmation. F1 New instrument clears only the working draft, not the library. New project clears the entire saved project. Ctrl+S writes the whole project including the working draft and committed programs. Save before closing REAPER. The original source files and the main LSFX map remain unchanged.

Project archive version 3 stores one shared sample pool with per-program references, names, zones and modulators. Versions 1 and 2 open as editable drafts; commit them to an address in F6. A project has one format; switching formats is disabled while committed programs exist. Export writes only committed slots: SF2 generates a single standard PCM16 SoundFont at the assigned bank/program addresses. SFZ generates a new folder with one SFZ per slot, shared Samples and Programs.csv (SFZ has no native MIDI bank table). Existing destination files/folders are never overwritten. Load the exported files manually in the main map. Project storage remains lossless. SF2 may need distinct sample entries where root, trim, loop or baked gain differ. Limits: 4096 unique samples and 1 GiB original audio across the project; up to 4096 committed zones plus the current draft. Native SF2 table limits also apply.

## TEST38 — Independent folder history and contextual modulation

Native file dialogs remember the last selected directory independently for Alt+O, bank import, program import, editor sample import, project open, project save, SF2/SFZ export; export-and-replace was removed in TEST39. History is saved in LSFX.settings; a missing directory falls back to Documents or Instruments. Cancelling leaves the last confirmed directory intact. The internal preset browser and Save As have separate directory memories; Save As still uses its existing preset-library folder selection.

F1 Enter on Format or name opens F2. F2 Enter opens the selected sample's zones: one zone goes straight to F3, multiple zones open a vertical selector (Up/Down, Home/End, Page Up/Down, Enter, Escape back). With no samples Enter opens import; otherwise use Import audio samples or Alt+I for additional imports. F2 arrows do not change the active zone unless Enter confirms a zone. Ctrl+Up/Down retains its global zone navigation outside the selector.

F4 filters custom modulators by the F3 destination. F5 selects a source with Up/Down (Page Up/Down ten, Home/End extremes), Enter or Tab to the assignment grid. From F4, F5 selects the current assignment's source; from F3 Low/High Velocity in SF2, F5 selects Velocity. F4/F5 share the same stored assignments per zone. In the assignment grid, Insert adds a zero-depth assignment, Delete removes it, Up/Down selects rows, Left/Right selects columns, Alt+Up/Down edits, Alt+Page changes ten steps, Alt+Left/Right changes the amount step, Alt+Home/End extremes, Backspace resets Amount. Ctrl+Up/Down changes zone. SF2 exposes general MIDI sources, allowed CCs, 33 synthesis destinations, two independent source curves/direction/polarity, amount and transform. Amount is in native SF2 generator units; positive attenuation lowers level. Matching custom SF2 modulators override matching engine defaults; default modulators are not listed yet. SFZ currently supports linear MIDI CC modulation of Level, Pan, Pitch, Cutoff and Resonance, with native SFZ opcodes. SF2/SFZ assignments are independent when switching format. Maximum 48 custom assignments per zone across both formats. Saved in project version 3; older version 1 and 2 projects remain readable. Export writes standard SF2 modulator records or SFZ opcodes. Modulation assignment changes affect new SF2 notes; received controllers act on active notes. SFZ definition changes retain the previous preview while rebuilding. Keyswitches, MIDI conditions, extended SFZ sources and default-modulator management are future work.

## TEST37.1 — Independent editor navigation and resident SF2/SFZ preview

Alt+T opens the editor with six pages: F1 format/name/project, F2 samples, F3 all parameters of the current zone, F4 modulation by destination, F5 modulation by source, F6 save/export. Ctrl+Tab / Ctrl+Shift+Tab cycle pages. No page buttons in the Tab order. Format changes with Up/Down only; navigation keys on buttons are consumed. Ctrl+Up/Down selects the previous/next zone from F2 through F5 without changing the selected sample. F2 Up/Down changes only the sample. F3 keeps the selected parameter when changing zone. Eight parameter rows per column, two visible columns per page; arrows navigate, Page Up/Down moves up to five within a column, Home/End column boundaries, Ctrl+Home/End entire grid; silent boundaries. Alt+Up/Down edits, Alt+Page changes ten steps, Alt+Home max/Alt+End min, Alt+Left/Right changes step (1 to 10000), Backspace resets. Insert adds a zone, Ctrl+D duplicates, Delete removes a zone, Ctrl+C/V copies zone settings preserving target sample, Ctrl+Z/Y undo/redo. F2 removes only unused samples; Space auditions the original PCM and stops on a second press. Ctrl+Enter stops sound; Escape returns to main plugin. Preview success/status messages are not spoken. Errors are announced.

F3 includes mapping, level/pan/pitch, key tracking, sample start/end, loop mode/start/end, choke, amplitude DAHDSR, low-pass cutoff/resonance, shared modulation envelope with pitch/filter depths, vibrato LFO, shared modulation LFO with filter/volume depths, reverb/chorus sends. SFZ additionally has One Shot, independent Choke Target, round robin, random range, trigger, choke mode/time, six filter types, velocity/key tracking, pitch bend range, pitch/amp/delay/offset randomization, stereo width/position, note polyphony and sustain switch. Both formats have Mod LFO Pitch; SF2 adds key scaling of hold/decay for both envelopes. SF2 uses exclusive class and supports off/continuous/sustain loops. Frame indices are inclusive; End means the last usable frame. Existing projects are opened with default values for newly added parameters. Switching to SF2 changes unsupported One Shot to Off; the SFZ-only choke target is not used in SF2. The preview is dry, so sends are stored/exported but not audible in preview. This is a practical subset of the two synthesis standards, not a complete SF2 modulator matrix or all SFZ opcodes.

SF2 preview now uses FluidSynth's virtual SoundFont API. Audio is decoded to resident PCM16 sample resources only when needed; parameter edits with the same sample list prepare new voice descriptors without re-encoding an SF2 or reloading the engine. Existing notes keep their initial voice settings; subsequent notes immediately use the new parameters. Raw sample audition parks the mapped engine for reuse. Changes involving newly imported/removed samples or a new format/host rate still need a background build. SFZ preview uses sfizz embedded base64 audio with two alternating instances on the worker. TEST37.1 fixes the loss of regions on repeated edits: sfizz 1.2.3 clears its FilePool on every load, including the same virtual path. Each reload therefore embeds and decodes all referenced samples, once per unique sample. The previous mapped preview stays available until the new regions are ready. Reopening an unchanged prepared project still reuses its resident engine without loading. Held SFZ voices are not transferred across swaps. No preview audio files are created on disk. Escape suspends playback without unloading the prepared editor; reopening an unchanged project at the same sample rate reuses the live instance immediately. Page, sample, zone, parameter, step, focus and undo/redo history are retained while the plugin instance exists. The normal main map and DSP remain separate; preview is dry Main 1/2 only. The worker waits when no updates are pending. No original files are touched.

## Instrument projects and exports

F2 imports mono/stereo WAV/AIFF/FLAC using Layer, Chromatic, Multisample or Velocity Layers. Original audio is held as immutable bytes in RAM, deduplicated and shared by zones and undo snapshots. Ctrl+S / Ctrl+Shift+S save a portable lossless ZIP project (`.lsfx-instrument`) with `project.xml` and internal `Samples/`. No external source paths required. Default folder: Documents/LSFX/Instruments. Project limits: 4096 samples/zones, 256 MiB per sample, 1 GiB unique original audio; decoded SF2 preview has a separate 1 GiB PCM16 limit; SFZ uses a conservative 1 GiB float PCM bound per preview instance, plus working buffers. The draft is not embedded in REAPER state: explicitly save the instrument project. F6 commits instruments into project slots and exports the committed library only. Existing destination files/folders are rejected. Export never changes the main map. Level is -60..0 dB. MIDI Learn, REAPER item import, editing existing SF2/SFZ, editing the default modulator list, keyswitches and CC-controlled articulations are still pending. All heavy I/O occurs on a worker.

## TEST33 — MIDI Reset

Ctrl+Alt+M restores MIDI playback defaults without unloading the sound library or resetting the mixer. Notes are stopped; SF2 channels are reset using FluidSynth's system reset and the virtual programs are rebound (bank 000/program 000, channel 10 bank 128/program 000; standalone SFZ follows the initial open-file policy). SFZ controllers are restored to instrument defaults, pitch wheel and channel pressure reset. Manual CC/generator overrides are cleared. Follow MIDI mode also restores the MIDI-controlled global FX profile; Manual mode preserves global FX settings. Channel gain, output assignments, compressors, SFZ instrument gain, note mixer and map remain intact. The reset is processed before incoming MIDI in the next audio block; it does not reload samples, and is unavailable while empty/loading. This is not a full reset of internal SFZ round-robin/keyswitch state or a guarantee of reproducing an arbitrary mid-song seek; REAPER can still send chased MIDI events after the reset. Ctrl+Enter remains Panic; Alt+I remains full initialization.

## Export SoundFont (Alt+E)

Exports the actual virtual map, including selected individual SF2 programs and banks only, into a standard standalone PCM16 SoundFont 2.01. Shared instruments and samples are reused within each source file; linked stereo samples, generators and modulators are retained. Exported preset names end with a short source filename label (up to eight ASCII characters, disambiguated if needed), or SFZ for converted instruments. The name is shortened as necessary to fit the standard 20-byte SF2 field (19 characters plus terminator). The output uses the virtual destination bank and program numbers, not the original addresses. No LSFX-specific gain, CC overrides, routing, compressors or effects are exported. Source banks are never overwritten. Choose a destination with the Windows Save dialog; Cancel/Escape cancels, including during export. The current map is unchanged. The worker streams PCM to a temporary file before replacing the destination.

SFZ sources are converted into single SF2 presets at their mapped addresses. Supported sampled regions include inherited global/master/group settings, includes and defines, relative sample paths, mono/stereo PCM, key/velocity ranges, pitch, pan, source volume, sample offsets and loops, amplitude envelopes, low-pass filters, and approximate standard SF2 modulation envelopes/LFOs/CC modulators. Sample audio is converted to PCM16; JUCE-supported audio formats are decoded offline. The same SFZ path is converted once per export, and identical sample slices/settings are reused. The SFZ conversion is approximate: unsupported opcodes, omitted regions, and clipping are reported. Round robin uses first position, random selection the midpoint, controller gates their initial values, keyswitches their declared default articulation. Release-triggered regions are omitted; one-shot is approximated by a long release. Oscillators without audio samples and missing/undecodable samples fail the export. No changes are made to source files or the map. Space or Enter dismisses the completion dialog.

SF3, 24-bit SF2, nonportable banks above 128, ROM samples or selected SF2 sample offsets outside nominal sample bounds remain unsupported. Invalid unused loop coordinates in old files are repaired. Deduplication is by source identity, not across unrelated source files. Original licenses continue to apply. Do not redistribute exports unless permitted by all source licenses.

## Note mixer and compatibility

Alt+Enter opens the note grid with MIDI learn off. Alt+M toggles learning; plain arrows navigate, Alt+arrows edit. The four columns are Output, Level, Pan and Pitch. Assignments are per virtual bank/program, affect newly started SF2 voices and are saved in LSFX presets and host state, not exported to SF2. A note with Channel Default follows the channel's route. SFZ per-note processing is not yet implemented; SFZ channel-level audio routing is available. The 128 internal SF2 mixer groups include 112 additional channel/destination combinations; Alt+S reports exhaustion. Special legato modes that reuse a voice are not verified. EQ is not included in this release.

Older preset route indices are preserved. Previously recorded host automation for routing may need to be recreated due to the expanded normalized choice range. Older LSFX versions cannot interpret map deletion markers.
