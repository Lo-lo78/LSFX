# LSFX 0.0.1 TEST10
Experimental accessible VST3 instrument for REAPER. SF2 uses FluidSynth; SFZ uses sfizz 1.2.3. One file per instance, no conversion. SF2 supports 16 MIDI channels; SFZ currently accepts channel 1 only. SF3 is not a target. The existing plugin identifier and XML state tag are retained for TEST1 project compatibility; remove the old VST3 bundle before installing LSFX.

Open SF2 or SFZ using the existing editor. SFZ samples must remain in their original relative locations. Bank and Program controls apply only to SF2. In REAPER's generic parameter UI, SF2 interpolation is Linear / Fourth order (default) / Seventh order; SF2 effects are Off (default) / Reverb / Chorus / Both. These settings and the instrument path persist in state. Existing TEST1 states without the new fields use the lighter defaults. SFZ uses 128 voices, SF2 256; see TEST6 controls below. SF2 idle bypass now waits for no active voices and two seconds below -100 dBFS on both pre-master dry/native-wet and final effects signals; it works with effects enabled and ignores MIDI clock/active sensing. CPU improvement is not measured yet.

Build: push to main and download TEST10 Windows x64 artifact from Actions. The workflow uses JUCE, FluidSynth via vcpkg and recursively fetched sfizz sources. See TESTING.md and THIRD_PARTY.md. Experimental build, not verified on Windows in the authoring environment.

TEST4: retains the TEST3 duplicate cxxopts alias fix and patches the pinned sfizz MSVC runtime to /MD (and /MDd in Debug), matching JUCE and vcpkg static-md. Also normalizes nested sfizz targets and saves build logs even on failure. DSP and editor behavior are unchanged from TEST2.

TEST5: fixes the sfizz license filename in packaging (LICENSE, not LICENSE.md), and records packaging logs. No DSP changes.


## TEST6 - accessible parameter grid

On initial editor entry, focus is requested for Open SF2 or SFZ. The Parameters button immediately follows it. Alt+L opens/focuses the grid, Alt+V focuses its value, Esc or Alt+C closes it. Alt+O (Open), Alt+M (MIDI channel), Alt+B (Bank), Alt+P (Program), Alt+G (Output gain), Alt+A (Panic), Alt+S (Read status) focus the named main control without activating it.

Browse: Up/Down select adjacent parameters; Left/Right and Page Up/Down move five rows; Home/End first/last parameter. Type a letter to select the next matching name (Shift reverses). Enter or Tab goes to the value slider. In the value slider, Up/Down changes the value; Left/Right chooses step 1, 5, 10, 15 or 20; Page Up/Down changes numerical values by step times 40. Enumerated settings and channel selection always change by one. Home/End select the first/last parameter even in value mode. Alt+Home/End set minimum/maximum. Enter returns to the grid; Alt+Up/Down or Alt+Page Up/Down can also edit from the grid. Backspace resets generator offsets or the common engine settings when editing; it does not reset arbitrary CCs. Main output gain uses the same step behavior.

SF2: output gain, selected channel, interpolation, effects, MIDI volume/pan/expression/modulation/FX sends, and per-channel generator offsets for filter, AHDSR, tuning and modulation. Offsets are additive native SoundFont units, not absolute zone values. Zero offset preserves the instrument's programmed values. Some changes affect newly triggered notes; effects sends require effects enabled.

SFZ: output gain, live sample quality and CCs explicitly labeled by the instrument. The loader queries the initial CC values through sfizz's read-only OSC interface before publishing the synth. If a query is unavailable the value is shown as Instrument default (not read), not guessed. An explicit edit sends MIDI CC, and the file is never rewritten. Unlabeled opcodes and keyswitches are not yet a complete instrument editor. SFZ remains single instrument on MIDI channel 1.

State version 3 retains old gain, quality, effects, file and programs. Explicit grid CC and generator edits are saved in the project/preset and restored on load or sample-rate change. Incoming MIDI changes update display; only explicit editor overrides are saved, so MIDI sequences continue to drive their own events. Opening another file starts with its own defaults. No change to tested dependency/packaging fixes; no extra scan of all controls each audio block unless an edit is pending. Dynamic CCs/generator offsets are internal controls, not individual host automation parameters yet.

## TEST7 - GS-style effects, output stage and CPU diagnostics

Effects is now a global switch for either engine. The independent Delay level controls a separate stereo/ping-pong master delay (default off). Eight GS-named reverb types: Room 1/2/3, Hall 1/2, Plate, Delay, Panning Delay. Eight GS-named chorus types: Chorus 1/2/3/4, Feedback Chorus, Flanger, Short Delay, Short Delay with Feedback. Names follow Roland GS; these are LSFX approximations, not exact Sound Canvas algorithms or full GS macro SysEx emulation. SF2 Room/Hall/Plate and Chorus 1-4 use FluidSynth and native per-channel CC91/93 sends. Other variants and independent delay are master inserts; SFZ uses a JUCE reverb and LSFX master delay/modulation, in addition to the SFZ instrument's own internal effects. No per-channel send for these master effects yet. Reverb Delay/Panning Delay use the shared delay time/feedback; Short Delay variants are 35 ms. Chorus rate/depth apply to modulation types, feedback applies to Feedback Chorus, Flanger and Short Delay with Feedback only. Reverb damping, width and time scale apply to Room/Hall/Plate. Defaults are LSFX settings, not Roland numeric presets. All new global parameters are exposed to the host and saved in XML version 4; Backspace resets them in the value editor. Existing states receive defaults.

The final stereo stage is adapted from LJuno-116 0.99.67: peak-linked Glue (1 ms attack, 4 ms release, threshold 0.055, ratio 2:1, gain 0.4), historical soft limiter (0.98 threshold, 0.15 slope), then master gain times 2. An adjustable input trim (0 to +24 dB, default +12 dB) compensates for FluidSynth's low internal level; also applied to SFZ. Soft limiter is not a brick-wall ceiling: high trim/output gain can exceed 0 dBFS. Adjust gain as needed. New output stage changes loudness and dynamics of previously saved projects.

SF2 rendering skips only after no active voices and two seconds below -100 dBFS before the output stage; notes, MIDI controls, patch/effect changes wake it. SFZ keeps rendering because its trigger and internal effect semantics differ. Panic resets local effect state and releases SF2 sustain/sostenuto, then all sounds off; does not explicitly clear FluidSynth native effect buffers. If a MIDI block is lost during engine swap, a panic is requested to avoid stuck notes. Read status reports active engine voices, SF2 idle sleep and cumulative dropped engine-swap blocks. These diagnostics help isolate persistent CPU spikes; the actual root cause is not yet confirmed. No change to the working Windows dependency configuration. Tests/OutputStageTest.cpp is a standalone C++17 regression test for the new stage/delay; tested at 44.1/48/96 kHz. Full Windows build and REAPER behavior still need validation.

## TEST9 - focus, bounded grid, incremental search, output level

The initial focus request now follows LJuno's delayed native-peer readiness approach. It does not force focus out of the host FX chain or away from an already focused editor child; the editor root and title are ignored by accessibility. The grid is prepared before its focus transfer, and the destination is revealed before hiding the old panel. Leaving Parameters through an accelerator goes directly to the requested main control. The file chooser callback no longer forcibly steals focus after returning. Native popup keys remain native. Alt editing uses the actual originating control for its announcement; the timer no longer rewrites unchanged values. Read-only slider text boxes were replaced by visual readouts, leaving one accessible slider per value.

Grid navigation uses eight rows per column, two visible columns per page; borders stop navigation like LJuno rather than wrapping. Up/Down stays within the column, Left/Right moves to the same row of the previous/next column if it exists. Page Up/Down moves five within the column. Home/End and Ctrl+Home/End go to the first/last parameter of the full grid. Type a prefix within one second to search label/word starts (LJuno's search helper), repeat a single letter to cycle, Shift reverses. The painted grid shows the selected cell and supports mouse selection; the accessible native selector remains the single grid control.

In Value, Up/Down changes the value, Left/Right selects step, Page Up/Down changes numerical values by 40 times the selected step, Home/End sets minimum/maximum. Alt+arrows, Alt+Page and Alt+Home/End perform the same edits directly from Grid without changing focus. The main Output gain slider supports the same step, page and boundary keys, also with Alt. Existing choice settings still advance one option at a time. Backspace resets supported parameters from Grid or Value. Esc closes the grid, native host Escape is not intercepted on the main panel.

The output stage provides an additional factor of 2 (6.02 dB below the final knee) for both SF2 and SFZ, after the existing Glue and master gain. A continuous sample-level soft ceiling starts at 0.90 and approaches 0.999 in either polarity. It is not a true-peak limiter. Existing parameter IDs, gain range, defaults and state format stay unchanged; previously saved projects also sound louder. No changes to the engines, FX, CI dependencies or runtime linking. Standalone C++ output/delay and incremental search tests passed locally; Windows build and actual focus/Alt-key handling in REAPER/NVDA must still be tested.

## TEST10 - VST3 multichannel MIDI Program Change

JUCE 8.0.12's default MIDI mapping has 130 entries per channel (CC, pressure, pitch bend) but no entry for Program Change; its controller lookup lacks the bound check for index 130. LSFX patches the pinned wrapper at configure time, appending sixteen mappings without renumbering existing CCs and providing 16 input-channel units and their 128-program lists for standard VST3 host delivery. Both host paths route to the same MIDI event at its supplied offset. Numeric host program names are bank-independent, while LSFX's editor displays the loaded SF2 preset names. Program numbers are zero-based. SF2 events at identical timestamps are processed as SysEx, bank select, program change, then other events to handle VST3's separate controller queues and event lists. No changes to the sound engines, grid or gain from TEST9. Read status now reports received MIDI program changes and the last channel/program (counts received events, not necessarily successful selection). Wait until the file is loaded before starting playback; events arriving before the engine is ready are not replayed. REAPER delivery and Windows compilation require validation.
